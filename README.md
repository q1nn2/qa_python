# BooksCollector — unit-тесты на Pytest

Учебный проект по автоматизации тестирования Python-класса `BooksCollector`. Тесты проверяют добавление книг, работу с жанрами, возрастные ограничения и избранное.

## Стек

- Python
- Pytest
- параметризация тестов
- Pytest fixtures

## Покрытые сценарии

- добавление книги с допустимой длиной названия;
- граничные значения длины названия: 1, 40, 0 и 41 символ;
- защита от повторного добавления одной книги;
- установка и получение жанра;
- фильтрация книг по жанру;
- исключение жанров с возрастным рейтингом из детской подборки;
- добавление книги в избранное без дубликатов;
- удаление книги из избранного;
- получение списка избранных книг.

Общий объект `BooksCollector` для тестов создаётся через fixture в `conftest.py`, поэтому каждый тест получает независимый экземпляр.

## Структура

```text
qa_python/
├── main.py       # тестируемый класс BooksCollector
├── conftest.py   # fixture для тестов
├── tests.py      # unit-тесты
└── README.md
```

## Запуск

```bash
pip install pytest
pytest -v tests.py
```
