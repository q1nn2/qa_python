# Sprint 4. Тесты для BooksCollector

Проект содержит юнит-тесты для класса `BooksCollector`.

## Реализованные тесты

- добавление книги с допустимой длиной названия;
- запрет добавления книги с пустым названием или названием длиннее 40 символов;
- запрет повторного добавления одной и той же книги;
- установка допустимого жанра для добавленной книги;
- проверка, что у новой книги жанр не указан;
- получение книг выбранного жанра;
- исключение жанров с возрастным рейтингом из списка книг для детей;
- добавление книги в избранное без дубликатов;
- удаление книги из избранного;
- получение списка избранных книг.

## Запуск тестов

```bash
pytest -v tests.py
```
